## Knowledge base (Qdrant MCP)

- For questions about saved facts, notes, decisions, test data, or Kubernetes
  resources, ALWAYS call `qdrant-find` first, even if you think you already know
  the answer from memory files.
- When asked to save or remember project knowledge, use `qdrant-store`,
  not the built-in memory files.
- If `qdrant-find` and built-in memory disagree, report both and say which
  source each came from.
